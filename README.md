# computervision-Facial-Gender-Recognition-IndonesiaAI

Project 1 : Face Recognition 

Proyek Face Recognition ini mengembangkan sistem berbasis Artificial Intelligence (AI) untuk mengenali wajah manusia secara otomatis. Dalam prosesnya, proyek ini mengadopsi Machine Learning, Deep Learning, dan Computer Vision untuk menciptakan model klasifikasi wajah yang presisi dan efisien. Sistem ini memanfaatkan dataset CelebA serta menggunakan PyTorch sebagai framework utama dalam membangun model deep learning berbasis Convolutional Neural Networks (CNN).

Algoritma yang digunakan : Googlenet, Resnet, dan VGG
Dataset yang digunakan : https://mmlab.ie.cuhk.edu.hk/projects/CelebA.html
Tools yang digunakan : Python, GoogleCollab, OpenCV, ScikitLearn, Keras, Streamlit

Semoga bermanfaat :)
